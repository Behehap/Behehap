## 🚀 Featured Project

### [RJQ — Reliable Job Queue](https://github.com/Behehap/RJQ)

A job queue built in Go, designed to explore reliability, concurrency, scheduling, and observability.

- Concurrent workers and worker supervision
- Priority-based scheduling and job preemption
- Persistent storage and crash recovery
- Automatic retries and failure handling
- Prometheus metrics and Grafana dashboards
- Containerized development environment with Docker Compose

This project reflects my interest in building reliable systems and understanding the engineering challenges behind background job processing.
